# Tandem

AI-powered collaborative workspace that turns team conversations into persistent project intelligence.

## Architecture

Frontend
→ FastAPI Backend
→ Whisper
→ AI / ROPA
→ Supabase
→ Team State

## Project Structure

- `frontend/` — Next.js frontend
- `backend/` — FastAPI backend, Whisper and database integration
- `ai/` — ROPA and LLM intelligence
- `shared/` — API contracts and schemas
- `docs/` — Project documentation
